让我们一步一步计算直接映射 Cache 中访问主存地址 15H 的 tag、index 和 offset。

**1. 理解地址结构和 Cache 结构**

- **主存地址:** 主存被分为 32 个 Block，我们需要地址来定位到具体的 Block 和 Block 内的字节。
- **Cache 结构:** Cache 被分为 4 个 Block。 对于直接映射，每个主存 Block 只能映射到 Cache 中一个特定的 Block 位置。
- **Block 大小:** 每个 Block 为 4 字节。这意味着 Block 内偏移地址需要 2 位 (因为 22 = 4)。

**2. 确定 Offset 位数 (Offset Field Size)**

- 由于每个 Block 大小为 4 字节，我们需要用 **2 位** 来表示 Block 内的偏移量 (0, 1, 2, 3)。
- 因此，Offset 字段占 **2 位**。

**3. 确定 Index 位数 (Index Field Size)**

- Cache 有 4 个 Block。 我们需要用 **2 位** 来索引这 4 个 Cache Block (0, 1, 2, 3)。
- 因此，Index 字段占 **2 位**。
4
- **主存总字节数:** 32 Blocks * 4 字节/Block = 128 字节
- 寻址 128 字节需要 **7 位** (27 = 128)。 所以，总的 **字节地址位数是 7 位**。

现在重新计算 Tag 位数：

- 总位数 (字节地址位数) = 7 位
- Offset 位数 = 2 位
- Index 位数 = 2 位
- Tag 位数 = 总位数 - Offset 位数 - Index 位数 = 7 - 2 - 2 = **3 位**



重新提取 Tag, Index, Offset (使用 7 位二进制地址，并修正 Tag 位数)：

- 将 15H 转换为 7 位二进制 (因为最大地址是 128 字节， 寻址到 15H 应该可以用 7 位足够表示， 15H = 21D = 10101B , 补齐 7 位为 0010101B )
    
- 7 位二进制地址： **001 01 01B**
    
- **Offset (最低 2 位):** **01B** = 1 (十进制) = **1H** (十六进制)
    
- **Index (中间 2 位):** **01B** = 1 (十进制) = **1H** (十六进制)
    
- **Tag (最高 3 位):** **001B** = 1 (十进制) = **1H** (十六进制)
    
==**验证 Index 计算:**==

- ==主存 Block 号== = 字节地址 / Block 大小 = 21 / 4 = 5 (向下取整，Block 编号从 0 开始)
- 主存 Block 号 5 (二进制) = 101B
- ==Index== = 主存 Block 号 mod Cache Block 数量 = 5 mod 4 = 1
- Index = 1 (十进制) = 01B (二进制) = **1H** (十六进制)， 与我们之前直接从地址中提取的结果一致。

**最终结果:**

对于要访问的主存地址 15H：

- **Tag:** **1H**
- **Index:** **1H**
- **Offset:** **1H**
