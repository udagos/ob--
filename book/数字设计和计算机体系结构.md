节点丫同时被高电平和低电平驱动，称为竞争

数字设计师经常使用符号 X 来表示在真值表中不用关心的值
**当 X 出现在真值表中时，它表示不重要的值。当 X 出现在电路中时，它的意思是电路节点有未知或者非法的值。**
### z
Z 表示节点既没有被高电平驱动也没有被低电平驱动。节点被称为浮空（floa­ting）、高阻态（highimpedance）或者高 Z 态
这个浮空的节点可能是 0 也可能是 1, 也有可能是在。和 1 之间的电压

三态缓冲器（tristatebuffer）有 3 种可能输出。**当使能端为真时**，三态缓冲器作为一个简单的缓冲器，传送输入值到输出端。**当使能端为假的时候**，输出被置为高阻态（Z）

**三态缓冲器经常在连接多个芯片的总线中使用**。每个芯片可以通过三态缓冲器连接共享的存储总线，如图 2・42 所示。在某个时刻只允许有一个芯片的使能信号有效，并向总线驱动数据。**而其他芯片的输出必须为浮空**，以防止它们和正与存储器通信的芯片产生竞争

## 传输延迟和最小延迟
组合逻辑电路的时序特征包括传输延迟 (propagationdelay)和最小延迟
传输延迟气是输入改变直到对应的一个或多个输出达到最终的值所经历的最长时间。最小延迟小是一个输入发生变化到任何一个输出开始改变的最短时间。

## 毛刺
但是, **一个输入信号的改变可能会导致多个输出信号的改变**。这被称为毛刺 (glitch)或者冒险 (hazard

**只要读取输出之前的等待时间和传输延迟一样长，出现毛刺就不会有问题，这是因为输出最终将稳定在正确的值**
**可以在已有实现中增加门电路来避免毛刺。**
这从卡诺图中最容易理解。**图 2-77 显示了从 ABC=0 11变成 ABC=001 时 B 上输入的改变使得从一个主蕴涵项圈移到另外一个。这个变化穿过了卡诺图中两个主蕴涵项的边界，从而可能会产生毛刺。**

总之，**一个信号的变化在卡诺图中穿越两个主蕴涵项的边缘时会导致毛刺。我们能够通过在卡诺图中增加多余的蕴涵项盖住这些边缘以避免毛刺**。这当然以增加额外的硬件成本为代价。

#### 乘法
**乘法（MUL**）将两个 32 位数相乘，产生 32 位结果
**UMULL（无符号相乘长整型）和 SMULL**（有符号相乘长整型）将两个 32 位数字相乘并生成 64 位乘积
UMULL RI, R2, R 3, R 4   执行 R 3 和 R 4 的无符号乘法。乘积的最低有效 32 位放在 R 1 中，最高有效 32 位放在 R2中。
**这些指令中的每一个还具有相乘-累加变体 MLA、SMLAL 和 UMLAL**。MLA 指令实现两个 32 位的数 (可以为无符号，也可以为有符号)的乘积，再将乘积加上第 3 个操作数，并将结果存放到一个 32 位的寄存器中
### 条件标志
ARM **条件标志**（也称为状态标志）**有负（N）、零（Z）、进位（C）和溢出（V）**
这些标志由 ALU 设置（见 5.2.4 节），并保存在 32 位当前程序状态寄存器（**CPSR**）的前 4位中
![[Pasted image 20240508190405.png]]
==**设置状态位的最常用方法是使用比较（CMP）指令**==, 该指令从第一个源操作数中减去第二个源操作数
如果第一个数是大于或等于第二个数的无符号值，则减法将产生进位，设置 C 标**志。** 
==**当运算的结果产生进位或者减法运算没有借位的话 C 置位**==。移位操作也会影响 C 位，C 的值是最后一个被移位器移出的位值，当然这个被移出的位值如果为1那么 C 值就为1。但也有特殊指令会造成 C 位改变，这个如果自己在编程时会用到 C 位最好参考一下汇编指令手册，确认一下对应的指令是否对 C 位有特殊影响。

在来说一下 ==V 位，这个位是针对有符号的加法/减法及比较的==，溢出，何为溢出呢，如果运算的结果大于等于 2 的 31 次方，或者小于负的 2 的 31 次方则 V 置位


N 位是用来检测运算结果是否为负数时比较有用。什么是负数呢，在计算机系统，负数通常用二进制的补码来表示，如果最高有效位被置位，则该二进制补码为负数。也就是说==**运算结果最高位为 1 那么 N 位就置位**。==

### 函数调用 
ARM 系统的惯例是：调用函数在调用之前要将 **4 个参数**分别放在 R 0〜R 3 中，被调用函数在完成之前将**返回值**放入 R0中
**调用函数**将返回地址（returnaddress）存在链接寄存器 **LR** 中，与此同时它使用分支和链接指令（BL）跳转到被调用函数入口
被调用函数必须保证已保存寄存器（R 4〜R 11, LR）以及用于存放临时变量的栈（stack）不被修改。

### thump 指令集
但通常有局限性，包括： 
• 只访问底部 8 个寄存器。 
• 将寄存器重复用作源和目标。 
• 支持更短的时间。 
• **缺乏条件执行。**
