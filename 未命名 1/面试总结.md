# 总结面试问题


1.      最小系统：单片机最小系统就是能够让单片机工作的最简单的系统组成。电源、晶振和复位电路

2.      晶振的作用：通电后会产生机械震荡，可以给单片机提供稳定的时钟源（单片机所有工作都是在时钟信号控制下运行），晶振提供时钟频率越高，单片机的运行速度也就越快。

3.      1. 讲⼀下stm32的时钟系统

4.      时钟在MCU中的作⽤，就好⽐于⼈类的⼼脏⼀样不可或缺。STM32有多个时钟源可以使⽤。因为STM32拥有丰富的外设资源，不同外设使⽤的时钟也会不⼀样，同时我们要知道时钟越快，功耗就越⼤，抗电磁⼲扰的能⼒就会减弱，因此，⽐较复杂的MCU 都会采⽤多时钟来解决这些问题。

5.      STM32 有5个时钟源:HSI、HSE、LSI、LSE、PLL。

6.      ①、HSI是⾼速内部时钟，RC振荡器，频率为16MHz，精度不⾼。可以直接作为系统时钟或者⽤作PLL时钟输⼊。

7.      ②、HSE是⾼速外部时钟，可接⽯英/陶瓷谐振器，或者接外部时钟源，频率范围为4MHz~26MHz。

8.      ③、LSI是低速内部时钟，RC振荡器，频率为32kHz，提供低功耗时钟。主要供独⽴看门狗和⾃动唤醒单元使⽤。

9.      ④、LSE是低速外部时钟，接频率为32.768kHz的⽯英晶体。作为RTC时钟；

10.   ⑤、PLL为锁相环倍频输出。提供2-16倍的倍频输出。

11.   C语⾔中堆和栈的区别；推挽输出是什么？

12.   栈的好处是：方便、快、有效避免内存碎片化            堆栈：类似于队列，堆栈是个简单的数据存储结构。堆栈中数据进出的顺序很重要，举个例子，餐厅的盘子堆，盘子洗完要堆到上面，而不是插到下面的某个位置（相信不会有人那么做）。当厨师要用到盘子时从最上面的开始拿。即最先放在堆里的盘子会被最后一个用到。定义：堆栈就是只能在一端插入和删除数据的链表，这个端就叫做栈顶（top），最后一个添加的数据第一个被删除。因此，这也叫后进先出（链表或是先进后出链表。

13.   而局部变量只是自己在用，放在数据段中纯属浪费空间，没有必要，故将其放在自己的栈中，随时可以清理，真正体现了局部的意义。函数参数为什么放在栈区呢？第一也是其局限性导致，只有这个函数用这个参数，何必将其放在数据段呢？二是因为函数是在程序执行过程中调用的，属于动态的调用，编译时无法预测何时调用及被调用的次数，函数的参数及返回值都需要内存来存储，如果是递归调用的话，参数及返回值需要的内存空间也就不确定了，这取决于递归的次数。

14.   （1）管理方式不同。栈由操作系统自动分配释放，无需我们手动控制；堆的申请和释放工作由程序员控制，容易产生内存泄漏；

15.   （2）空间大小不同。每个进程拥有的栈大小要远远小于堆大小。

16.   （3）生长方向不同。堆的生长方向向上，内存地址由低到高；栈的生长方向向下，内存地址由高到低。

17.   （4）分配方式不同。堆都是动态分配的，没有静态分配的堆。栈有 2 种分配方式：静态分配和动态分配。

18.   （5）分配效率不同。显然，堆的效率比栈要低得多。

19.   （6）存放内容不同。栈存放的内容，函数返回地址、相关参数、局部变量和寄存器内容等。而堆中具体存放内容是由程序员来填充的。

20.   IO口8种状态

　一、推挽输出：输出高，低电平，连接数字器件; 一般是指两个[三极管](https://so.csdn.net/so/search?q=%E4%B8%89%E6%9E%81%E7%AE%A1&spm=1001.2101.3001.7020)分别受两互补信号的控制，总是在一个三极管导通的时候另一个截止。

开漏输出:一般只能输出低电平，输出端相当于三极管的集电极. 要得到高电平状态需要上拉电阻才行.

三、浮空输入：顾名思义就是浮在空中，上面用绳子一拉就上去了，下面用绳子一拉就沉下去了。外部电路是什么状态，就是什么状态

上拉输入：上拉就是把电位拉高，比如拉到Vcc。上拉就是将不确定的信号通过一个电阻嵌位在高电平！

2、下拉输入：就是把电压拉低，拉到GND。

3、模拟输入：模拟输入是指传统方式的输入。数字输入是输入PCM数字信号，即0，1的二进制数字信号，通过数模转换，转换成模拟信号，经前级放大进入功率放大器（功率放大器中也是模拟信号）。

21.   五、复用开漏输出、复用推挽输出：可复⽤功能就是外设的配置。（即并非作为通用IO口使用）。

22.   4、模拟输⼊，这个我没⽤到，也不太理解，套⽤⼀下前辈的话：模拟输⼊是指传统⽅式的输⼊，数字输⼊是输⼊PCM数字信号，即0,1的⼆进制数字信号，通过数模转换，转换成模拟信号，经前级放⼤进⼊功率放⼤器，功率放⼤器还是模拟的。

45.   RAM 、ROM都是数据存储器。RAM 是随机存取存储器，掉电失忆。ROM (一次写入，反复读取)。常规上ROM是用来存储固化程序的，RAM是用来存放数据的。由于FLASH ROM比普通的ROM读写速度快，擦写方便，一般用来存储用户程序和需要永久保存的数据。譬如说，现在家用的电子式电度表，它的内核是一款单片机，该单片机的程序就是存放在ROM里的。电度表在工作过程中，是要运算数据的，要采集电压和电流，并根据电压和电流计算出电度来。电压和电流时一个适时的数据，用户不关心，它只是用来计算电度用，计算完后该次采集的数据就用完了，然后再采集下一次，因此这些值就没必要永久存储，就把它放在RAM里边。然而计算完的电度，是需要永久保存的，单片机会定时或者在停电的瞬间将电度数存入到FLASH里。

51.   1.什么是嵌入式系统？

52.   嵌入式系统是一种特殊的计算机系统，专门设计用于执行预定义任务。它通常隐藏在产品中，例如智能手机、汽车、仪器仪表和家用电器中，并被嵌入在其他设备中，以便实现特定的功能和任务。

53.   2.芯片打孔是什么？

54.   芯片打孔是通过把芯片的针脚外露出来，实现与外部系统的通信。这种方法由于能够有效地节省空间，已被广泛应用于嵌入式系统中。

55.   3.在处理器和微控制器之间有什么区别？

56.   处理器是一种为通用计算设计的芯片，而微控制器是一种为特定应用而设计的计算机系统。微控制器通常具有内置的存储器、输入/输出端口、时钟和其他外设，它能够在单个芯片上实现完整的系统，从而简化了整个系统的设计过程。

57.   4.什么是硬实时系统？

58.   硬实时系统指的是必须在预定时间内完成任务的系统，通常需要在实时的反应时间内处理数据和输出。这种系统通常用于需要高度精确操作的应用，如机器人控制、医疗设备和航空航天。

59.   5.为什么处理器需要中断？

60.   中断是一种机制，通常用于在程序执行期间停止或暂停程序的执行，以处理紧急事件或优先事项。对于嵌入式系统而言，中断通常用于实现设备驱动程序、定时器以及其他类似的任务，以确保系统可以及时响应外部事件。

61.   6.什么是DMA？

62.   DMA (Direct Memory Access)是一种用于将数据在系统中传输的技术，它允许数据在不需要CPU干预的情况下传输到内存、外设或其他设备。DMA是许多嵌入式系统中的常见技术，因为它可以帮助提高设备和系统的效率。

63.   7.什么是嵌入式系统的并发？

64.   并发是指在同一时间内处理多个任务的能力。对于嵌入式系统而言，这是非常重要的，因为许多设备需要在同一时间内执行多个任务。例如，一个多任务的操作系统可以允许音频、视频、网络和用户界面应用程序同时运行。

65.   8.什么是内存对齐？

66.   内存对齐是指将变量或数据存储在内存中的方法，以便于处理器的读取操作。这个过程确保每个变量或数据都存储在内存中的适当位置，从而帮助处理器更快地访问内存并提高系统的性能。

67.   9.什么是交叉编译？

68.   交叉编译是一种用于在一台主机上为不同的架构创建可执行代码的编译方法。这种方法在嵌入式系统中非常广泛，因为它可以消除由于新编译的代码无法在目标设备上运行而造成的问题，并且可以加快编译和开发的速度。

69.   10.什么是RTOS？

70.   RTOS (Real-Time Operating System)是一种特殊的操作系统，它专门设计用于实时嵌入式系统。RTOS通常具有可预测的响应时间，并实现了实时般的多任务管理、任务切换和内存管理等特性。

71.   11.什么是死锁？

72.   死锁是指系统中多个资源或任务互相等待释放的状态，因而无法继续执行下去。对于嵌入式系统而言，死锁可能导致系统崩溃或停止响应，导致重大的安全隐患，因此应该避免出现死锁的情况。

73.   12.什么是RTOS中的信号量？

74.   RTOS中的信号量是一种特殊的同步原语，帮助多个任务协调共享资源的使用。信号量通常用于控制与共享资源的访问，而避免出现竞争条件和死锁等问题。

75.   13.什么是GPIO？

76.   GPIO是指通用输入/输出端口，它可以在嵌入式系统中用于连接各种外部设备，如传感器、驱动器和开关等。使用GPIO可以实现与外部设备的通信和交互，并实现嵌入式系统的功能。

77.   14.什么是嵌入式系统的固件？

78.   固件是嵌入式系统中的软件，它通常具有硬件特定的代码，与操作系统密切相关。固件可以实现许多嵌入式系统的主要功能，并且可以在系统上启动前和运行时进行更新和修改。

79.   15.什么是嵌入式系统的闪存？

80.   闪存是一种非易失性存储器，通常用于存储嵌入式系统的代码和数据。与其他种类的存储器不同，闪存可以在设备被关闭后保留其内容，并在下次开机时重新读取。

81.   16.什么是嵌入式系统的Bootloader？

82.   Bootloader是一种嵌入式系统的程序，它在系统启动时运行，并负责从存储设备加载主操作系统或其他应用程序。固件更新、故障诊断和系统测试等都需要使用Bootloader来完成。

83.   17.嵌入式系统如何使用USART？

84.   USART是通用同步/异步收发器，常用于嵌入式系统中的串行通信。USART可以实现与其他设备或系统的通信，例如GPS接收机、无线调制解调器等，从而实现数据和命令的交互。

85.   18.什么是I2C？

86.   I2C是一种广泛用于嵌入式系统中的串行通信协议，可用于连接多个设备和传输数据。I2C协议通常由多个设备组成，其中一个设备是主设备，其他设备是从设备，从而实现数据的传输和交换。

87.   19.什么是SPI？

88.   SPI是一种广泛用于嵌入式系统中的串行通信协议，用于连接设备和外围设备之间的通信。SPI协议通常包含一个主设备和多个从设备，使用二进制信号来传输数据、命令和状态等。

89.   20.什么是Wi-Fi？

90.   Wi-Fi是一种常用于嵌入式系统中的无线网络技术，可用于连接多个设备以及传输数据和命令。Wi-Fi是一种常见的无线协议，可以实现设备之间的高速数据传输和通信。

91.   21.什么是蓝牙？

92.   蓝牙是一种广泛用于嵌入式系统中的无线通信技术，它可以用于连接各种设备并传输数据。蓝牙技术在智能手机、汽车和智能家居等嵌入式系统中得到广泛应用。

4.      I2C通信：SCL SDA即使有很多芯片，也可以进行简单的线路连接，采用一主多从模式。I2C两根线分别是时钟线和数据线，写数据是时钟线和数据线共同作用，所以他要么是在发送数据，要么是在读取数据，空闲时两根线都处于高电平状态，时钟为高电平，数据为下降沿，发送起始信号，接着发送7位设备地址码，匹配外设，然后进入读写数据为。读数据置1，写数据置0，再到应答信号（从机发送到主机）收到信号回复0，没有收到或者读写完成回复1然后到设备寄存器地址，返回应答信号，对存储器的寄存器写入数据，发送应答信号0，写入停止位，时钟信号为高电平数据信号为上升沿。读数据，存储器把寄存器的数据发送给单片机。

5.      CAN总线：应用最多的是汽车领域，通过CAN，众多ECU挂在CAN总线上就可以组成局域网通信了。CAN通信需要专门的CAN收发芯片，单片机的发送和接收线，逻辑1是高电平，逻辑0是低电平。经过Can收发器后普通信号转化为差分信号，差分线是两个信号表示为一个信号，如果我们发送一个低电平两根线分别输出3.5V和1.5V形成2V电压差，表示逻辑0，发送高电平时两根线输出都是2.5V，表示逻辑1。Can收发器也可以把接收到的差分信号转化为普通的电平信号，在发给单片机。起始位为逻辑0，接下来为11位识别码，根据11位识别码就可以知道这一帧信号发送给哪一个设备，接下来用来区分数据帧或远程请求帧，接下来是控制码，用来控制数据长度，下面一位是预留位，逻辑0.接下来4位DLC位，16位CRC码，循环冗余校验位，CRC界定符，两位ACK码，7位数据结束位

6.      SPI通信：采用一主多从模式，只能有一个主机，一个或者多个从机，需要四条信号线SS、SSK、MOSI、MISO。片选信号线SS通过给片选信号线高低电平来确定给哪一个从机通信，低电平时片选有效，时钟信号线SCK，发送信号线MOSI，接收信号线MISO，串行同步通信，数据线和时钟线两根线配合，才能给存储器发送数据，只有在时钟信号上升沿，信号才被采样，有几个上升沿就会传输多少个数据，读数据要先写入起始位1，读数据操作码10告诉从机要读数据，发送要读取地址，得到数据。

8.      While循环：当表达式为真，则执行下面的语句；语句执行完之后再判断表达式是否为真，如果为真，再次执行下面的语句；然后再判断表达式是否为真……就这样一直循环下去，直到表达式为假，跳出循环。 do…while 是先执行一次循环体，然后再判别表达式

**10.**   链表是一种常见的基础数据结构，结构体指针在这里得到了充分的利用。链表可以动态的进行存储分配，也就是说，链表是一个功能极为强大的数组，他可以在节点中定义多种数据类型，还可以根据需要随意增添，删除，插入节点。链表都有一个头指针，一般以head来表示，存放的是一个地址。链表中的节点分为两类，头结点和一般节点，头结点是没有数据域的。链表中每个节点都分为两部分，一个数据域，一个是指针域。说到这里你应该就明白了，链表就如同车链子一样，head指向第一个元素：第一个元素又指向第二个元素；……，直到最后一个元素，该元素不再指向其它元素，它称为“表尾”，它的地址部分放一个“NULL”（表示“空地址”），链表到此结束。作为有强大功能的链表，对他的操作当然有许多，比如：链表的创建，修改，删除，插入，输出，排序，反序，清空链表的元素，求链表的长度等等。

12.   静态变量(static)：有局部变量，也有全局变量。  
特点：  
（1）它占据一个永久性的存储单元。随着文件的存在而存在。

（2）静态局部变量是在编译时赋初值，在程序执行期间，一旦存储单元中的值改变，就不会再执行赋初值的语句。未赋初值的变量其值为0。
