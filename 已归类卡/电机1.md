# 步进电机梯形加减速
使用加减速呢?
硬件驱动细分器与软件的细分参数或定时器分频参数设置不当时启动电机时,
会遇见步进电机有啸叫声但是不会转动, 这是因为软件产生脉冲的频率大于步进电机的启动频率，发生丢步或者堵转的情况，或者也可以理解为由于步进脉冲变化过快, 转子由于惯性的作用跟不上电信号的变化

这种算法是一种在加速过程和减速过程中加速度不变的匀变速控制算法, 由于速度变化的曲线有折点, 所以在启动、停止、匀速段中很容易产生冲击和振动。
![[Pasted image 20241126084954.png]]

**调整脉冲之间的时间间隔就可以改变速度。**
![[Pasted image 20241126085528.png]]
•t0表示脉冲发送的起始时刻•t1表示脉冲发送的第二个时刻•t2表示脉冲发送的第三个时刻•tt表示定时器的计数周期•c0表示定时器从t0~t1时刻的定时器计数值•c1表示定时器从t1~t2时刻的定时器计数值•δt表示两个脉冲之间的间隔时间



![[Pasted image 20241126085152.png]]
上图中一共是三个不同变量与时间的变化曲线, 分别是加速度与时间、速度与时间和位置与时间的曲线



![[Pasted image 20241126085352.png]]
在ω-t图中是梯形加减速模型中的加速部分中,
红色竖线表示的是脉冲发生的位置,由加速的方向看 (从左到右), 在图上两个相邻之间的脉冲之间的距离越来越近
根据 δt=ct 计数周期不变,  计数值越来越小也就意味着脉冲之间的间隔时间变短了, 频率变快了, 直接影响步进电机转的变快了
在θ-t图中, 脉冲每产生一次就对应着θ轴上的一小格,ω-t图中工产生6次脉冲就对应θ-t中的6次位置的变化。

* @function 步进电机加速时间表和对应的速度表生成函数  
* @param MinMotorSpeed 最小速度值，单位pps  
* @param MaxMotorSpeed 最大速度值，单位pps  
* @param SpeedUpStep 加速步数  
* @param SpeedTimeTable 加速表时间缓冲区指针 单位us  
* @param Coeffic 系数，最终时间=系数*实际时间  
* @return Null  
* @note 半步加速表  
**/  
static void CaluteStepMotorSpeedUpTable(U16 MinMotorSpeed, U16 MaxMotorSpeed, U16 SpeedUpStep, U16 * SpeedTimeTable, U16 Coeffic)  
{  
	U32 i;  
	U32 lwSpeedUpTime;  
	U32 MinMotorFreq;  
	U32 MaxMotorFreq;  
	  
	MinMotorFreq = MinMotorSpeed;  
	MaxMotorFreq = MaxMotorSpeed;  
	  
	F64 lfSpeedUp = 2*(MinMotorFreq + MaxMotorFreq)*(MaxMotorFreq - MinMotorFreq)*1.0/(sqrt((2.0*SpeedUpStep - 3)*(2*SpeedUpStep - 3) + (F32)(MaxMotorFreq*MaxMotorFreq*1.0/(MinMotorFreq*MinMotorFreq)) - 1) + (2.0*SpeedUpStep - 3));  
	F64 lfSpeedUpConst = MinMotorFreq - (F32)(lfSpeedUp/(2*MinMotorFreq));  
	  
	for(i = 0; i < SpeedUpStep; i++)  
	{  
		lwSpeedUpTime = (U16)(1000000.0 * Coeffic * (F64)(2.0/(sqrt(1.0*lfSpeedUpConst*lfSpeedUpConst + 2.0*i*lfSpeedUp) + (F64)sqrt(1.0*lfSpeedUpConst*lfSpeedUpConst + (2*i - 1)*1.0*lfSpeedUp))));  
		SpeedTimeTable[i] = lwSpeedUpTime;  
	}  
	SpeedTimeTable[0] = (U16)(1000000.0 * Coeffic/(MinMotorFreq));  
	return;  
}
