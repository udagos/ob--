# rtt双向链表的后插入
```
rt_inline void rt_list_insert_after(rt_list_t *l, rt_list_t *n)
{
    l->next->prev = n;                      (1)
    n->next = l->next;                      (2)

    l->next = n;                    (3)
    n->prev = l;                    (4)
}
```
