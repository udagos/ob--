# RTT (RT-Thread) 信号量和互斥信号量用法示例

RT-Thread 提供了信号量 (semaphore) 和互斥信号量 (mutex) 两种同步机制，下面分别介绍它们的用法示例。

## 1. 信号量 (Semaphore) 用法

信号量主要用于线程间的同步和资源计数。

### 创建和初始化信号量

```c
#include <rtthread.h>

/* 静态方式创建信号量 */
static struct rt_semaphore static_sem;
rt_sem_init(&static_sem, "stat_sem", 1, RT_IPC_FLAG_FIFO);

/* 动态方式创建信号量 */
rt_sem_t dynamic_sem = rt_sem_create("dyn_sem", 1, RT_IPC_FLAG_FIFO);
```

### 信号量使用示例

```c
/* 生产者线程 */
void producer_thread_entry(void *parameter)
{
    while (1)
    {
        /* 生产资源... */
        rt_thread_mdelay(500);
        
        /* 释放信号量 */
        rt_sem_release(&static_sem);
        rt_kprintf("producer release semaphore\n");
    }
}

/* 消费者线程 */
void consumer_thread_entry(void *parameter)
{
    while (1)
    {
        /* 获取信号量 - 等待 */
        rt_sem_take(&static_sem, RT_WAITING_FOREVER);
        rt_kprintf("consumer take semaphore\n");
        
        /* 消费资源... */
        rt_thread_mdelay(1000);
    }
}

int semaphore_sample(void)
{
    rt_thread_t producer, consumer;
    
    /* 创建生产者线程 */
    producer = rt_thread_create("producer",
                              producer_thread_entry,
                              RT_NULL,
                              512,
                              5,
                              10);
    if (producer != RT_NULL)
        rt_thread_startup(producer);
    
    /* 创建消费者线程 */
    consumer = rt_thread_create("consumer",
                              consumer_thread_entry,
                              RT_NULL,
                              512,
                              6,
                              10);
    if (consumer != RT_NULL)
        rt_thread_startup(consumer);
    
    return 0;
}
```

## 2. 互斥信号量 (Mutex) 用法

互斥信号量主要用于线程间对共享资源的互斥访问。

### 创建和初始化互斥信号量

```c
#include <rtthread.h>

/* 静态方式创建互斥信号量 */
static struct rt_mutex static_mutex;
rt_mutex_init(&static_mutex, "stat_mutex", RT_IPC_FLAG_FIFO);

/* 动态方式创建互斥信号量 */
rt_mutex_t dynamic_mutex = rt_mutex_create("dyn_mutex", RT_IPC_FLAG_FIFO);
```

### 互斥信号量使用示例

```c
static int shared_resource = 0;

/* 线程1 */
void thread1_entry(void *parameter)
{
    while (1)
    {
        /* 获取互斥锁 */
        rt_mutex_take(&static_mutex, RT_WAITING_FOREVER);
        
        /* 访问共享资源 */
        shared_resource++;
        rt_kprintf("thread1: shared_resource = %d\n", shared_resource);
        
        /* 释放互斥锁 */
        rt_mutex_release(&static_mutex);
        
        rt_thread_mdelay(500);
    }
}

/* 线程2 */
void thread2_entry(void *parameter)
{
    while (1)
    {
        /* 获取互斥锁 */
        rt_mutex_take(&static_mutex, RT_WAITING_FOREVER);
        
        /* 访问共享资源 */
        shared_resource--;
        rt_kprintf("thread2: shared_resource = %d\n", shared_resource);
        
        /* 释放互斥锁 */
        rt_mutex_release(&static_mutex);
        
        rt_thread_mdelay(500);
    }
}

int mutex_sample(void)
{
    rt_thread_t thread1, thread2;
    
    /* 创建线程1 */
    thread1 = rt_thread_create("thread1",
                             thread1_entry,
                             RT_NULL,
                             512,
                             5,
                             10);
    if (thread1 != RT_NULL)
        rt_thread_startup(thread1);
    
    /* 创建线程2 */
    thread2 = rt_thread_create("thread2",
                             thread2_entry,
                             RT_NULL,
                             512,
                             6,
                             10);
    if (thread2 != RT_NULL)
        rt_thread_startup(thread2);
    
    return 0;
}
```

## 主要区别

1. **信号量**:
   - 可以用于线程同步和资源计数
   - 允许多个线程同时访问资源 (取决于初始计数值)
   - 没有所有权概念，任何线程都可以释放信号量

2. **互斥信号量**:
   - 专门用于互斥访问共享资源
   - 同一时刻只允许一个线程访问资源
   - 有所有权概念，只有获取锁的线程才能释放锁
   - 支持优先级继承，防止优先级反转问题

在实际应用中，根据需求选择合适的同步机制：
- 需要控制对共享资源的独占访问时使用互斥信号量
- 需要线程间同步或资源计数时使用信号量
