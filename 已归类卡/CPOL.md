SPI (Serial Peripheral Interface) 协议作为一种常见的同步串行通信协议，其灵活性也体现在它支持四种不同的通信格式，也称为 **SPI 模式** 或 **SPI 时钟模式**。这四种模式主要由两个参数决定： **时钟极性 (CPOL)** 和 **时钟相位 (CPHA)**。

让我详细解释这四种 SPI 通信格式，并通过图表辅助你理解：

**核心概念： CPOL 和 CPHA**

*   **CPOL (Clock Polarity - 时钟极性):**  ==CPOL 决定了 SPI 时钟信号 (SCLK) 在 **空闲状态** 的电平。==
    *   ==**CPOL = 0:**  SCLK 在空闲状态时为 **低电平**。==
    *   ==**CPOL = 1:**  SCLK 在空闲状态时为 **高电平**。==

*   **CPHA (Clock Phase - 时钟相位):** ==CPHA 决定了数据在 SCLK 的 **哪个时钟沿** 被 **采样** (读取) 和 **移位** (改变)。==
    *   ==**CPHA = 0:**  数据在 SCLK 的 **第一个时钟沿** (取决于 CPOL) **被采样**，在 **第二个时钟沿** **被移位**。==
    *   ==**CPHA = 1:**  数据在 SCLK 的 **第二个时钟沿** (取决于 CPOL) **被采样**，在 **第一个时钟沿** **被移位**。==

**四种 SPI 模式**

根据 CPOL 和 CPHA 的组合，SPI 定义了四种模式，通常用 Mode 0, Mode 1, Mode 2, 和 Mode 3 来表示。

**1. SPI Mode 0 (CPOL = 0, CPHA = 0)**

*   **CPOL = 0:**  SCLK 空闲时为低电平。
*   **CPHA = 0:**  在 SCLK 的 **上升沿** 采样数据，在 **下降沿** 移位数据。

**时序关系:**

```
SCLK:   _|--|__|--|__|--|_  (空闲低电平)
         ^  ^  ^  ^
         |  |  |  |
采样点:  ^  ^  ^  ^ (上升沿采样)
移位点:    ^  ^  ^  ^ (下降沿移位)
MOSI/MISO: ---D---D---D---
```

*   **数据采样:**  在 **SCLK 的上升沿** (从低电平到高电平的跳变) 时，从 MOSI (Master Out Slave In) 或 MISO (Master In Slave Out) 线上 **读取数据**。
*   **数据移位:** 在 **SCLK 的下降沿** (从高电平到低电平的跳变) 时，进行 **数据位的移位** (通常是将数据位移入移位寄存器或从移位寄存器移出)。

**特点:**

*   最常用的 SPI 模式之一。
*   上升沿采样，下降沿移位。
*   适用于许多 SPI 从设备。

**2. SPI Mode 1 (CPOL = 0, CPHA = 1)**

*   **CPOL = 0:** SCLK 空闲时为低电平。
*   **CPHA = 1:** 在 SCLK 的 **下降沿** 采样数据，在 **上升沿** 移位数据。

**时序关系:**

```
SCLK:   _|--|__|--|__|--|_  (空闲低电平)
         ^  ^  ^  ^
         |  |  |  |
移位点:  ^  ^  ^  ^ (上升沿移位)
采样点:    ^  ^  ^  ^ (下降沿采样)
MOSI/MISO: ---D---D---D---
```

*   **数据采样:** 在 **SCLK 的下降沿** (从高电平到低电平的跳变) 时，从 MOSI 或 MISO 线上 **读取数据**。
*   **数据移位:** 在 **SCLK 的上升沿** (从低电平到高电平的跳变) 时，进行 **数据位的移位**。

**特点:**

*   也是常用的 SPI 模式。
*   下降沿采样，上升沿移位。
*   与 Mode 0 类似，但采样和移位时钟沿相反。

**3. SPI Mode 2 (CPOL = 1, CPHA = 0)**

*   **CPOL = 1:** SCLK 空闲时为高电平。
*   **CPHA = 0:** 在 SCLK 的 **下降沿** 采样数据，在 **上升沿** 移位数据。

**时序关系:**

```
SCLK:   -^--^-^--^-^--^-  (空闲高电平)
         ^  ^  ^  ^
         |  |  |  |
采样点:  ^  ^  ^  ^ (下降沿采样)
移位点:    ^  ^  ^  ^ (上升沿移位)
MOSI/MISO: ---D---D---D---
```

*   **数据采样:** 在 **SCLK 的下降沿** (从高电平到低电平的跳变) 时，从 MOSI 或 MISO 线上 **读取数据**。
*   **数据移位:** 在 **SCLK 的上升沿** (从低电平到高电平的跳变) 时，进行 **数据位的移位**。

**特点:**

*   SCLK 空闲时为高电平。
*   下降沿采样，上升沿移位。
*   注意区分 Mode 1 和 Mode 2 的 CPOL 不同。

**4. SPI Mode 3 (CPOL = 1, CPHA = 1)**

*   **CPOL = 1:** SCLK 空闲时为高电平。
*   **CPHA = 1:** 在 SCLK 的 **上升沿** 采样数据，在 **下降沿** 移位数据。

**时序关系:**

```
SCLK:   -^--^-^--^-^--^-  (空闲高电平)
         ^  ^  ^  ^
         |  |  |  |
移位点:  ^  ^  ^  ^ (下降沿移位)
采样点:    ^  ^  ^  ^ (上升沿采样)
MOSI/MISO: ---D---D---D---
```

*   **数据采样:** 在 **SCLK 的上升沿** (从低电平到高电平的跳变) 时，从 MOSI 或 MISO 线上 **读取数据**。
*   **数据移位:** 在 **SCLK 的下降沿** (从高电平到低电平的跳变) 时，进行 **数据位的移位**。

**特点:**

*   SCLK 空闲时为高电平。
*   上升沿采样，下降沿移位。
*   注意区分 Mode 0 和 Mode 3 的 CPOL 不同。

**总结表格**

为了更清晰地对比这四种模式，我总结如下表：

| SPI Mode | CPOL | CPHA | SCLK 空闲状态 | 数据采样时钟沿 | 数据移位时钟沿 |
| :-------- | :--- | :--- | :------------ | :------------ | :------------ |
| Mode 0    | 0    | 0    | 低电平        | 上升沿         | 下降沿         |
| Mode 1    | 0    | 1    | 低电平        | 下降沿         | 上升沿         |
| Mode 2    | 1    | 0    | 高电平        | 下降沿         | 上升沿         |
| Mode 3    | 1    | 1    | 高电平        | 上升沿         | 下降沿         |

**如何选择 SPI 模式**

选择哪种 SPI 模式 **取决于你所使用的 SPI 从设备的要求**。

*   **查看从设备的 SPI 规格书 (Datasheet)：** 这是最可靠的方法。  从设备的规格书会明确指出它支持哪种或哪些 SPI 模式。
*   **尝试不同的模式：**  如果规格书没有明确说明，你可以尝试不同的模式，看看哪种模式可以正常通信。  通常 Mode 0 和 Mode 3 是最常见的，可以先尝试这两种模式。
*   **注意兼容性：** 主设备和从设备必须使用 **相同的 SPI 模式** 才能正常通信。

**配置 SPI 控制器**

在嵌入式系统开发中，你需要配置 SPI 控制器 (通常是微控制器或 SoC 上的 SPI 外设) 的 CPOL 和 CPHA 参数，以选择正确的 SPI 模式。  具体的配置方法会因不同的硬件平台和 SPI 驱动库而异，但通常都会提供相应的 API 或寄存器来设置 CPOL 和 CPHA。
