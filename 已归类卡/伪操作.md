### **ARM 汇编伪操作（Directives）完全指南**

伪操作（Directives）是汇编器提供的**控制命令**，用于指导汇编过程，但**不会生成机器指令**。以下是 ARM 汇编中所有重要伪操作的分类详解：

---

#### **1. 数据定义伪操作**
| 伪操作           | 作用            | 示例                 | 备注                   |
| ------------- | ------------- | ------------------ | -------------------- |
| `.byte`       | 定义 8 位数据      | `.byte 0x55`       | 可定义多个值：`.byte 1,2,3` |
| `.hword`      | 定义 16 位数据     | `.hword 0x1234`    | Thumb 代码常用           |
| `.word`       | 定义 32 位数据     | `.word 0xDEADBEEF` | ARM 标准字              |
| `.asciz`      | 定义 NULL 结尾字符串 | `.asciz "Hello"`   | 自动添加 \0              |
| `.ascii`      | 定义无结尾字符串      | `.ascii "RAW"`     | 不自动添加 \0             |
| `.space n`    | 分配 n 字节未初始化空间 | `.space 100`       | 通常用于缓冲区              |
| `.fill n,val` | 填充 n 个 val 值  | `.fill 10, 0xFF`   | 内存初始化                |

**示例**：
```assembly
.data
array:  .byte 1, 2, 3      @ 3字节数组
msg:    .asciz "Error!"    @ 带\0的字符串
buffer: .space 256         @ 256字节缓冲区
```

---

#### **2. 符号控制伪操作**
| 伪操作             | 作用          | 示例                |
| --------------- | ----------- | ----------------- |
| `.global sym`   | 声明全局符号      | `.global main`    |
| `.extern sym`   | 声明外部符号      | `.extern printf`  |
| `.weak sym`     | 声明弱符号（可被覆盖） | `.weak hook_func` |
| `.equ val,expr` | 定义常量        | `.equ MAX, 100`   |
| `.set var,expr` | 定义可重定义变量    | `.set counter, 0` |

**示例**：
```assembly
.equ SYS_EXIT, 0x11
.global _start
_start:
    MOV R0, #SYS_EXIT
```

---

#### **3. 段与内存布局控制**
| 伪操作          | 作用                          | 示例                     |
|----------------|-------------------------------|--------------------------|
| `.text`        | 切换到代码段                  | `.text`                 |
| `.data`        | 切换到数据段                  | `.data`                 |
| `.rodata`      | 切换到只读数据段              | `.rodata`               |
| `.bss`         | 切换到未初始化数据段           | `.bss`                  |
| `.section name` | 自定义段                      | `.section .isr_vector`  |
| `.align n`     | 按 2^n 字节对齐               | `.align 2` (4字节对齐)  |
| `.org addr`    | 设置当前位置计数器             | `.org 0x1000`           |

**示例**：
```assembly
.section .vectors
.word _stack_top     @ 栈顶地址
.word _reset_handler @ 复位向量
```

---

#### **4. 条件汇编与宏**
| 伪操作          | 作用                          | 示例                     |
|----------------|-------------------------------|--------------------------|
| `.if expr`     | 条件汇编开始                  | `.if DEBUG == 1`        |
| `.else`        | 条件汇编 else 分支            | `.else`                 |
| `.endif`       | 条件汇编结束                  | `.endif`                |
| `.macro name`  | 定义宏                        | `.macro SAVE_REGS`      |
| `.endm`        | 结束宏定义                    | `.endm`                 |
| `.rept n`      | 重复生成代码 n 次             | `.rept 3 \n NOP \n .endr` |

**宏示例**：
```assembly
.macro DELAY cycles
    .rept \cycles
    NOP
    .endr
.endm

DELAY 10  @ 插入10个NOP
```

---

#### **5. 调试与元信息**
| 伪操作          | 作用                          | 示例                     |
|----------------|-------------------------------|--------------------------|
| `.file "name"` | 设置源文件名                  | `.file "startup.s"`     |
| `.line n`      | 设置行号（调试用）            | `.line 42`              |
| `.loc n`       | 设置调试位置                  | `.loc 1 5`              |
| `.type sym,type` | 设置符号类型                 | `.type main, %function` |
| `.size sym,len` | 设置符号大小                 | `.size array, 100`      |

---

#### **6. 其他特殊伪操作**
| 伪操作          | 作用                          | 示例                     |
|----------------|-------------------------------|--------------------------|
| `.include "file"` | 包含其他汇编文件             | `.include "defs.s"`     |
| `.thumb`       | 切换到 Thumb 模式             | `.thumb`                |
| `.arm`         | 切换到 ARM 模式               | `.arm`                  |
| `.code 16/32`  | 指定指令集宽度                | `.code 16` (Thumb)      |
| `.ltorg`       | 强制生成文字池                | `.ltorg`                |

---

### **伪操作 vs 伪指令对比**
| **特征**       | **伪操作（Directives）**       | **伪指令（Pseudo-instructions）** |
|----------------|-------------------------------|-----------------------------------|
| **是否生成机器码** | ❌ 不生成                     | ✅ 生成（转换为真实指令）         |
| **作用阶段**    | 汇编阶段                      | 汇编阶段                         |
| **典型用途**    | 控制汇编器行为                | 简化编程                         |
| **示例**       | `.word`, `.global`, `.if`     | `LDR=`, `ADR`, `PUSH`            |

---

### **完整应用示例**
```assembly
.equ STACK_SIZE, 1024

.section .bss
_stack:
    .space STACK_SIZE  @ 分配栈空间

.section .text
.global _start
.arm                 @ 使用 ARM 指令集
_start:
    LDR SP, =_stack + STACK_SIZE  @ 初始化栈指针
    BL main            @ 调用主函数
    B .                @ 无限循环

.thumb_func           @ 标记为 Thumb 函数
main:
    PUSH {LR}         @ 保存返回地址
    MOV R0, #42
    POP {PC}          @ 返回
```

---

### **关键总结**
1. **伪操作不生成代码**，仅控制汇编过程
2. **数据定义**用 `.byte/.word`，**内存布局**用 `.section/.align`
3. **条件汇编**和**宏**可大幅提升代码复用性
4. **调试信息**（如 `.file`）对生成可调试目标文件很重要
5. 与伪指令不同，伪操作是**汇编器命令**而非指令语法糖

掌握这些伪操作可以编写更专业、可维护的 ARM 汇编代码，特别是在嵌入式开发和操作系统底层编程中。

## **1. 符号定义伪操作**

### **(1) 初始化内存分配**
| 伪操作       | 数据类型    | 功能说明         | 示例                      |
| --------- | ------- | ------------ | ----------------------- |
| `DCB`     | 字节（8位）  | 初始化字节数组      | `DCB 0x01, 0x02`        |

## **完整综合示例**
```assembly

BUFFER_SIZE  SETA  256       @ 定义缓冲区大小

AREA  |.text|, CODE, READONLY
EXPORT  main
IMPORT  init_hardware

main  PROC
    IF  :DEF:DEBUG
    MOV  R0, #0xDEAD        @ 调试标记
    ENDIF

    BL   init_hardware
    LDR  R1, =buffer
    MOV  R2, #BUFFER_SIZE
    B    .
    ENDP
END
```
