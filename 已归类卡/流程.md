## 处理中断向量表
```
    .align  5
.globl vector_irq
vector_irq:
    stmfd   sp!, {r0-r12,lr}

    vmrs    r0,  fpexc
    vmrs    r1,  fpscr
    /* up to 16 doubleword per vstm */
    vstmdb  sp!, {d16-d31}
    vstmdb  sp!, {d0-d15}
    @ TODO: add support for Common VFPv3.
    @       Save registers like FPINST, FPINST2
    stmdb   sp!, {r1}
    stmdb   sp!, {r0}

    bl      rt_interrupt_enter
    bl      rt_hw_trap_irq
    bl      rt_interrupt_leave

    /* we need to restore the VFP context anyway(either
    rt_hw_context_switch_interrupt_do or not) */
    ldmia   sp!, {r0}       @ get fpexc
    vmsr    fpexc, r0
    ldmia   sp!, {r1}       @ get fpscr
    vmsr    fpscr, r1
    vldmia  sp!, {d0-d15}
    vldmia  sp!, {d16-d31}

    @ if rt_thread_switch_interrupt_flag set, jump to
    @ rt_hw_context_switch_interrupt_do and don't return
    ldr     r0, =rt_thread_switch_interrupt_flag
    ldr     r1, [r0]
    cmp     r1, #1
    beq rt_hw_context_switch_interrupt_do

    ldmfd   sp!, {r0-r12,lr}
    subs    pc, lr, #4
```
1. **保存寄存器状态**
    
    - `stmfd sp!, {r0-r12,lr}`：将寄存器r0到r12以及链接寄存器lr的值保存到堆栈中。
2. **保存VFP（浮点）寄存器状态**
    
    - `vmrs r0, fpexc`：将VFP异常寄存器fpexc的值加载到r0中。
    - `vmrs r1, fpscr`：将VFP状态寄存器fpscr的值加载到r1中。
    - `vstmdb sp!, {d16-d31}`：将VFP双字寄存器d16到d31的值保存到堆栈中。
    - `vstmdb sp!, {d0-d15}`：将VFP双字寄存器d0到d15的值保存到堆栈中。
    - `stmdb sp!, {r1}`：将寄存器r1的值保存到堆栈中。
    - `stmdb sp!, {r0}`：将寄存器r0的值保存到堆栈中。
3. **调用中断处理函数**
    
    - `bl rt_interrupt_enter`：调用中断进入处理函数。
    - `bl rt_hw_trap_irq`：调用硬件陷阱中断处理函数。
    - `bl rt_interrupt_leave`：调用中断离开处理函数。
4. **恢复VFP寄存器状态**
    
    - 通过以下指令依次将之前保存的VFP寄存器状态恢复：
        - `ldmia sp!, {r0}`：加载fpexc的值。
        - `vmsr fpexc, r0`：将r0的值存储到VFP异常寄存器fpexc中。
        - `ldmia sp!, {r1}`：加载fpscr的值。
        - `vmsr fpscr, r1`：将r1的值存储到VFP状态寄存器fpscr中。
        - `vldmia sp!, {d0-d15}`：从堆栈中加载VFP双字寄存器d0到d15的值。
        - `vldmia sp!, {d16-d31}`：从堆栈中加载VFP双字寄存器d16到d31的值。
5. **处理线程切换标志**
    
    - 通过以下指令检查线程切换标志，若设置则跳转到线程切换处理函数：
        - `ldr r0, =rt_thread_switch_interrupt_flag`：加载线程切换标志的地址。
        - `ldr r1, [r0]`：将线程切换标志的值加载到r1中。
        - `cmp r1, #1`：将r1与1进行比较。
        - `beq rt_hw_context_switch_interrupt_do`：若相等，则跳转到线程切换处理函数。
6. **恢复寄存器状态并返回**
    
    - `ldmfd sp!, {r0-r12,lr}`：从堆栈中恢复之前保存的寄存器状态。
    - `subs pc, lr, #4`：将链接寄存器 lr 的值减去4，然后将结果存储到程序计数器 pc 中，实现返回。

```
void rt_hw_trap_irq()
{
    void *param;
    unsigned long ir;
    unsigned long fullir;
    rt_isr_handler_t isr_func;
    extern struct rt_irq_desc isr_table[];

    fullir = arm_gic_get_active_irq(0);
    ir = fullir & GIC_ACK_INTID_MASK;

    /* get interrupt service routine */
    isr_func = isr_table[ir].handler;

    if (ir != 29)
    {
        if (isr_func)
        {
            param = isr_table[ir].param;
            /* turn to interrupt service routine */
            isr_func(ir, param);
        }
    }
    else
    {
        if (isr_func)
        {
            param = isr_table[ir].param;
            /* turn to interrupt service routine */
            isr_func(ir, param);
        }
    }

    /* end of interrupt */
    arm_gic_ack(0, fullir);
}
```

这段代码是一个处理中断的函数。以下是对代码中每个部分的解释：

1. **获取中断信息**
    
    - `fullir = arm_gic_get_active_irq(0)`：获取当前活动的中断。
    - `ir = fullir & GIC_ACK_INTID_MASK`：从全中断信息中提取中断ID。
2. **获取中断服务函数**
    
    - 通过`isr_table[ir].handler`获取中断ID对应的中断服务函数。
3. **执行中断服务函数**
    
    - 如果中断ID不等于29，且存在中断服务函数`isr_func`，则执行以下操作：
        - 从`isr_table[ir].param`获取参数并存储到`param`中。
        - 调用中断服务函数`isr_func(ir, param)`。
4. **结束中断处理**
    
    - `arm_gic_ack(0, fullir)`：确认中断处理完毕，发送中断确认信号。

这段代码的主要作用是根据中断 ID 获取对应的中断服务函数，并执行该中断服务函数。在处理中断后，通过发送中断确认信号来结束中断处理过程。

## rt_hw_interrupt_install
```
rt_isr_handler_t rt_hw_interrupt_install(int vector, rt_isr_handler_t handler,
        void *param, char *name)
{
    rt_isr_handler_t old_handler = RT_NULL;

    if (vector < MAX_HANDLERS)
    {
        old_handler = isr_table[vector].handler;

        if (handler != RT_NULL)
        {
#ifdef RT_USING_INTERRUPT_INFO
            rt_strncpy(isr_table[vector].name, name, RT_NAME_MAX);
#endif /* RT_USING_INTERRUPT_INFO */
            isr_table[vector].handler = handler;
            isr_table[vector].param = param;
        }
        /* set the interrupt to this cpu */
        arm_gic_set_cpu(0, vector, 1 << rt_cpu_get_smp_id());
    }

    return old_handler;
}
```
