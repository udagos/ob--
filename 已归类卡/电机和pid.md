pps 步进电机：脉冲每秒

步进电机的运转速度与输入的脉冲速度成等比例关系。脉冲速度快，电机转速就快；脉冲速度慢，电机转速就慢。

电机的转速 (RPM)与脉冲速度 (PPS, 又称 Hz)之间的关系如下：
转速 (RPM)=脉冲速度 (PPS 或 Hz)\*60➗(步进电机分割数/圈)

说明：
1. RPM 为一般电机的速度单位，即 rev/min，为每分钟电机所转的圈数；PPS 为步进、伺服电机的速度单位，即 pulse per second, 为每秒所送出的脉冲数。
2. 由于 RPM 与 PPS 的单位不同，所以转换的过程中要先将 PPS 的秒乘以 60变为分钟。
3. 步进电机分割数/圈，又代表让电机转一圈多必须送出的脉冲数。
4. 上述公式拆解后之单位表示为：rev/min=pulse/sec\*60\*1/分割数
实例：五相半步级角 0.36°时 (即 1000 分割/圈)
(1)电机的转速为 600 RPM 时，即相当于脉冲速度 10000 PPS；
(2)脉冲速度 3000 PPS，即相当于转速 180 RPM；

### 通过调参消除

要去掉超调就需要加快 PWM 下降速度，即适当增大比例和微分，提高灵敏性，此外，适当减小积分，降低速度累积作用
![[Pasted image 20240506104542.png]]
调节有一定效果，超调得到改善，我们继续增大比例，减小积分
![[Pasted image 20240506104603.png]]
超调已被消除，但系统灵敏性过高，稳态并不稳定
这就形成了，超调和稳定性难以兼顾的情况。增大比例去超调的同时，稳态性能变差



我们若调整为**一开始就以最大 PMW 开始 PID 调速，则去超调所需要的比例可有效降低，系统稳态性能会改善**
![[Pasted image 20240506104651.png]]
系统超调和稳定性都有改善，不过系统初始启动，发生震荡，说明比例减弱过多，适当提高比例

电机启动超调得到明显改善，但速度达到目标速度才启动 PID，由于惯性电机速度会有一个 10%以内的小超调，仍可优化。优化方式即速度未达到目标速度前提前启动 PID，经过实验发现，不同速度等级下，惯性大小基本相同。因而，不同速度等级时，启动 PID 算法的速度和目标速度差值为恒指即可。

注意：
1. 建议以最大 PWM 启动电机
以最大 PWM 启动，无论最后，你需要把电机速度稳定到多少，速度上升过程一定能达到该速度。这样可避免计算启动 PWM 以及担心该 PWM 不能达到目标速度等麻烦，更重要的是以最大 PWM 启动，速度上升快，在后续 PID 参数固定的情况下，启动整体过程时间最短。
2. 启动 PID 算法速度与目标速度差值要通过实验获取，既不可过大也不能过小
二者差值设置合理时，速度上升过程整体相对平滑。
当二者差值过小时，无法有效抑制最大 PWM 启动的速度惯性，导致速度出现小超调 ![[Pasted image 20240506105806.png]]
当二值差值过大时，则 PID 启动时速度静差较大，又会出现 PID 调节导致的超调，如下：![[Pasted image 20240506105822.png]]
1. **PID 算法启动时输出 PWM 初值，一定要比稳态值小**
![[Pasted image 20240506112701.png]]
PID 算法启动初值合理配置是 PID 去超调的核心，这是有理论依据的。PID 本质是一种线性控制器，直观表现为，当其不工作在饱和区域（即控制量为上下限）时，连续控制，PID 输出控制量可连接为一条平滑的曲线。我们先开环启动后闭环 PID 控制去超调，实际上是，不断增大实际速度值，当速度值和目标值相差不大时，开启 PID 控制，若 PID 初值配置在稳态值附近时。PID 本身的线性特性，让其在小范围做线性波动，就达到稳态。这实际上避免了 PID 启动时，目标值和实际值之间巨大的静差，控制器为消除静差运算出的较大的线性控制增量，引入较大系统惯性，进而引发较大超调。
需要注意的是，PID 启动时配置的 PWM 初值，一定要确保比稳态值小，**稳态值我们不精确知道，但可通过固定 PWM 和稳定速度比值大致求取**，求取结果虽不完全准确，但偏差不大，只需留足偏差余量即可。

若 PID 启动时配置的 PWM 初值比稳态值大时，历史能量输入过大，会助长超调，如下：
