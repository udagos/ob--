## PS-PL MIO-EMIO 信号和接口
由于 MIO 引脚数量有限, MIO 是 I/O 外设连接的基础。软件对 I/O 信号到 MIO 引脚的路由进行编程。
I/O 外设信号也可以通过 EMIO 接口路由到 PL
### I/O 外设 (IOP) 接口路由 
I/O 控制器信号的 I/O 复用不同
也就是说, 某些 IOP 信号仅在 MIO 引脚接口上可用，某些信号可通过 MIO 或 EMIO 访问, 而某些接口信号仅可通过 EMIO 访问
表 2-3 **显示了每个 I/O 外设的一些路由功能。**

### IOP 接口连接
对于大多数外设,I/O 信号的映射位置具有灵活性。路由功能显示在图2-4 
外围系统连接图如图图 2-3。

PS 外设的大多数 I/O 信号 (USB 除外)可通过 MIO 路由至 PS 引脚, 或通过 EMIO 路由至 PL 引脚。除千兆位以太网外
在互连方面, USB、以太网和 SDIO 外设连接到中央互连, 为六个 DMA 主设备提供服务

软件通过 AHB 互连访问仅限从机的 Quad-SPI 和 SMC 外设。
GPIO、SPI、CAN、UART和I2C仅保存控制器可通过APB总线访问。所有控制和状态寄存器也可通过APB互连进行访问,但SDIO控制器除外(每个控制器都有两个AHB接口)。该架构旨在平衡每个控制器接口的带宽需求。

### MIO 概览表 
每个 MIO 引脚均可使用 GPIO。引脚 0-31 由 GPIO 组 0 控制。引脚 32-53 由 G PIO 组 1 控制。MIO7 和 MIO8 只能用作输出。

### MIO 信号路由
通过 MIO 的信号路由由位于 slcr 寄存器组中的 MIO_PIN_[53:0]配置寄存器控制

MIO 使用四级
高速数据信号仅通过一级多路复用器进行路由。较慢的信号 (例如 UART 和 I 2 C 端口)通过所有四个多路复用器级进行路由

每个 MIO 引脚的路由由每个 MIO_PIN 寄存器中的多个位字段独立控制。
