**全相连映射的关键特点：**

在全相连 Cache 中，主存中的 **任何 Block** 都可以被放置到 Cache 中的 **任何一个 Block** 位置。 这意味着，当 CPU 要访问某个主存地址时，Cache 需要 **并行地** 检查**所有** Cache Block 的 Tag，看是否有匹配的。 由于没有固定的 “组” 或 “行” 的限制，全相连映射提供了最大的灵活性，但实现起来也相对更复杂，成本更高。

**计算步骤：**

1. **确定 Offset 位数 (Offset Field Size):**
    
    - Block 大小依然是 4 字节。 因此，Block 内偏移量仍然需要 **2 位** (22 = 4)。
    - Offset 字段 = **2 位**。
2. **确定 Index 位数 (Index Field Size):**
    
    - 在**全相连映射中，没有 Index 字段**。 因为不需要用 Index 来选择 Cache 中的特定位置，任何主存 Block 都可以放在任何 Cache Block。
    - Index 字段 = **0 位**。
3. **确定 Tag 位数 (Tag Field Size):**
    
    - 总的地址位数取决于主存的总容量。 主存有 32 个 Block，每个 Block 4 字节，总共 128 字节 (32 * 4 = 128)。
    - 寻址 128 字节的主存空间，需要 **7 位** 地址 (27 = 128)。
    - Tag 位数 = 总地址位数 - Offset 位数 - Index 位数 = 7 位 - 2 位 - 0 位 = **5 位**。
4. **将主存地址 15H 转换为二进制 (7 位):**
    
    - 15H 是十六进制，等于十进制的 21。
    - 21 转换为 7 位二进制： **0010101B**
5. **提取 Tag 和 Offset:**
    
    - 由于没有 Index 字段，我们只需要从二进制地址中划分 Tag 和 Offset。
    - **Offset (最低 2 位):** **01B**
	    - **Tag (剩余的全部高位，共 5 位):** **00101B**
6. **将二进制的 Tag 和 Offset 转换为十六进制：**
    
    - **Tag:** `00101B` = 5 (十进制) = **5H**
    - **Offset:** `01B` = 1 (十进制) = **1H**

**最终答案：**

对于要访问的主存地址 15H，在全相连映射 Cache 中：

- **Tag:** **5H**
- **Offset:** **1H**
