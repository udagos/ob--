
### 1. 内核架构 (Core)：最大的区别

这是“大脑”的区别。

- **STM32F1 (Cortex-M3):**
    
    - 纯整数运算内核。
        
    - **没有硬件浮点单元 (FPU)**。如果你在 F1 上做浮点运算（如 `float a = 3.14 * b`），编译器会将其转化为几十行汇编指令，效率极低，占用大量 CPU 时间。
        
- **STM32F4 (Cortex-M4F):**
    
    - 基于 M3 增加了 **DSP 指令集**（用于信号处理）和 **FPU（单精度浮点单元）**。
        
    - **硬件加速**：浮点运算通常只需 1 个指令周期。
        
    - **ART Accelerator**：ST 特有的自适应实时加速器，实现了“零等待”从 Flash 读取指令，让 CPU 跑得飞快。
        

### 2. 主频与性能 (Speed)

- **STM32F1:** 最高 **72 MHz**。
    
- **STM32F4:** 范围很广，从 **84 MHz** (F401) 到 **180 MHz** (F429/F446)。
    
    - 性能差距不仅在频率，F4 的单位赫兹性能（DMIPS/MHz）也更高。
        

### 3. 总线架构与 GPIO (Bus Matrix)

这是影响 IO 翻转速度和数据吞吐量的关键。

|**特性**|**STM32F1**|**STM32F4**|**影响**|
|---|---|---|---|
|**GPIO 挂载总线**|**APB2** (最高 72MHz)|**AHB1** (最高 180MHz)|F4 的 GPIO 翻转速度极快，理论可达总线速度的一半。|
|**DMA 控制器**|简单的 DMA，无 FIFO|增强型 DMA，**带 FIFO**|F4 的 DMA 可以缓存数据，减少总线冲突，突发传输更强。|
|**SRAM 结构**|只有一块连续 SRAM|分为 SRAM1, SRAM2, CCM|F4 的 **CCM (核心耦合内存)** 直接连在内核上，只能由 CPU 访问（DMA 无法访问），用于存放关键运算代码或堆栈，速度极快。|

### 4. 外设功能的差异 (Peripherals)

F4 的外设比 F1 强大得多，主要体现在以下方面：

- **ADC (模数转换):**
    
    - **F1:** 12位，1 MSPS（每秒采样 100 万次）。
        
    - **F4:** 12位，**2.4 MSPS 或更高**。且 F4 通常有 3 个 ADC，支持更复杂的多重采样。
        
- **USB:**
    
    - **F1:** 只有 USB 2.0 Full Speed (FS)。
        
    - **F4:** 支持 **USB OTG**，且很多型号支持 **High Speed (HS)**（需外接 PHY 芯片）。
        
- **高级接口 (F1 没有的):**
    
    - **DCMI:** 摄像头接口 (F407 及以上)。
        
    - **LTDC/DMA2D:** 液晶屏幕控制器和图形加速 (F429 等)。
        
    - **SAI:** 串行音频接口，用于高保真音频。
        

### 5. 开发与代码层面的区别 (Development)

这直接关系到你写代码的方式：

- **库的选择:**
    
    - **F1:** 绝大多数教程和老项目使用 **标准库 (Standard Peripheral Library, SPL)**。虽然 ST 已停止更新，但民间生态极好。
        
    - **F4:** 官方强推 **HAL 库** 或 **LL 库**。虽然 F4 也有标准库，但并不完善且很少人用。
        
- **GPIO 配置 (正如上一个回答):**
    
    - **F1:** `CRL/CRH` 寄存器，模式和速度混杂，通过“复用重映射 (Remap)”来改变引脚功能。
        
    - **F4:** `MODER`, `AFR` 等独立寄存器，通过“复用选择 (Alternate Function)”来指定引脚功能，**没有 Remap 的概念了**。
        
- **中断优先级:**
    
    - F1 和 F4 都使用 NVIC，但 F4 提供了更多的中断源和更灵活的优先级分组。
        



F1 和 F4 系列的区别。
 F1 采用 Crotex M3 内核，F429 采用 Crotex M4 内核。
 F1 最高主频 72MHz， F429 最高主频 180MHz。
 F429 具有单精度浮点运算单元，F1 没有浮点运算单元。
 F429 的具备增强的 DSP 指令集。F429 的执行 16 位 DSP 指令的时间只有 F1 的 30%~70%。F429
执行 32 位 DSP 指令的时间只有 F1 的 25%~60%。
 F1 内部 SRAM 最大 64K 字节，F429 SRAM 有 256K 字节（192K+64K+16K+64KB）。
 F429 有备份域 SRAM（通过 Vbat 供电保持数据），F1 没有备份域 SRAM。
 F429 从内部 SRAM 和外部 FMC 存储器执行程序的速度比 F1 快很多。F1 的指令总线 I-Bus 只接到
Flash 上，从 SRAM 和 FMC 取指令只能通过 S-Bus，速度较慢。F429 的 I-Bus 不但连接到 Flash 上，
而且还连接到 SRAM 和 FMC 上，从而加快从 SRAM 或 FMC 取指令的速度。
 F1 最大封装为 144 脚，可提供 112 个 GPIO；F429 最大封装有 216 脚，可提供 168 个 GPIO。
 F1 的 GPIO 的内部上下拉电阻配置仅仅针对输入模式有用，输出时无效。而 F429 的 GPIO 在设置为
输出模式时，上下拉电阻的配置依然有效。即 F429 可以配置为开漏输出，内部上拉电阻使能，而 F1
不行。
 F429 的 GPIO 最高翻转速度为 90MHz，F1 最大翻转速度只有 18MHz。
 F1 最多可提供 5 个 UART 串口，F429 最多可以提供 8 个 UART 串口。
 F1 可提供 2 个 I2C 接口，F429 可以提供 3 个 I2C 接口。
 F1 和 F429 都具有 3 个 12 位的独立 ADC，F1 可提供 21 个输入通道，F429 可以提供 24 个输入通
道。F1 的 ADC 最大采样频率为 1Msps，2 路交替采样可到 2Msps（F1 不支持 3 路交替采样）。F4
的 ADC 最大采样频率为 2.4Msps，3 路交替采样可到 7.2Msps。
 F1 只有 12 个 DMA 通道，F429 有 16 个 DMA 通道。F429 的每个 DMA 通道有 4*32 位 FIFO，F1
没有 FIFO。
 F1 的 SPI 时钟最高速度为 18MHz， F429 可以到 45MHz。
 F1 没有独立的 32 位定时器（32 位需要级联实现），F429 的 TIM2 和 TIM5 具有 32 位上下计数功
能。
 F1 和 F429 都有 2 个 I2S 接口，但是 F1 的 I2S 只支持半双工（同一时刻要么放音，要么录音）, 而 F429
的 I2S 支持全双工，放音和录音可以同时进行。
 从编程的角度来说，M3 和 M4 几乎没有区别
